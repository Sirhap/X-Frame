# 视频去水印页面覆盖规则

## 定位与导航

- 页面属于“快速工具”上下文，固定入口为 `/tools/watermark`，不伪装成动画项目内工序。
- 桌面沿用 64px 工具轨道；窄屏把六个工具入口平铺在顶部，并始终显示当前“去印”状态。
- 返回动作统一指向 `/tools`，不清除正在执行的本地导出任务。

## 工作区

- 中央视频画布优先，右侧 320px 参数栏依次排列来源、修复方式、选区和导出。
- 青色表示可操作与本地就绪，琥珀色表示当前选区，红色只表示引擎不可用或失败。
- 拖拽选区必须提供键盘替代：四角快捷选区、方向键移动、Shift + 方向键缩放。
- 上传、导出和进度状态使用可读文本及原生禁用语义，不只依赖颜色或动画。

## 响应式与性能

- 900px 以下切换为单列并保留全部工具导航；375px 与 812×375 横屏不得产生水平滚动。
- 视频容器预留 `aspect-ratio`，避免元数据加载时发生布局偏移。
- 画布只在播放和交互期间重绘；所有转场响应 `prefers-reduced-motion`。
