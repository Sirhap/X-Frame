# 受保护版本发布检查清单

任何一项未满足都不得部署或覆盖当前稳定版本。

2026-07-21 本地验收记录：Rust/WASM 单测与差分、最终生产审计、298 项 Node 测试、Cloudflare 门禁测试、Chromium/Firefox/WebKit 生产 WASM 专项以及 512/1024/2048 P95 门禁均已通过。仓库私有性、目标 CDN、可选受控模式部署和 AI 逆向演练仍须在实际发布环境确认，因此下列发布复选框不由本地构建自动勾选。

## 治理与输入

- [ ] 核对本次核心源码、夹具和算法文档只来自私有构建输入。
- [ ] 核对新增依赖版本、许可证、维护状态及 `package-lock.json`/Rust lockfile。
- [ ] 记录构建种子、客户构建标识、编译器版本和目标浏览器矩阵。
- [ ] 确认构建日志不含图片、视频、RGBA、掩码、文件名或像素摘要。

## 构建与安全

- [ ] 执行 `npm ci`、Rust release 构建、WASM 优化和去符号步骤。
- [ ] 执行 `npm run build:production`。
- [ ] 执行 `npm run audit:protected:final`，不得用普通隔离审计替代。
- [ ] 确认 HTML 只引用内容哈希资产，WASM 无 `name`、DWARF、源码路径或 Source Map。
- [ ] 确认生产 Worker 不包含同步敏感 JS 降级路径。
- [ ] 确认私有发布记录和回滚归档包含 manifest、种子和完整哈希。

## 功能、浏览器与隐私

- [ ] Development JS Adapter 与 Production WASM Adapter 通过相同产品合同测试。
- [ ] RGBA、掩码、距离场逐字节一致；浮点描述符满足误差合同。
- [ ] 预览、批量、修复、ZIP、动画回写、单帧隔离、取消、一次重启和版本不匹配通过。
- [ ] Chrome、Firefox、WebKit 的真实浏览器测试全部通过。
- [ ] 浏览器网络记录证明没有图片、视频、RGBA、掩码或处理结果上传。
- [ ] 受控模式下未授权、过期、错误 Origin、撤销版本和限频请求均无法获取 WASM。

## 性能与轮换

- [ ] 分别记录 512、1024、2048 的 P95；核心处理劣化不超过批准阈值。
- [ ] 分列 WASM 下载/初始化、Worker 传输、执行、PNG 编码和峰值内存。
- [ ] 对保护变体单独记录体积、兼容性和性能差异。
- [ ] 比较版本 A/B，确认内容哈希和布局轮换，旧抓取脚本不能直接按文件名复用。
- [ ] 重大版本完成只提供 `dist/` 的 AI 逆向演练并记录指标。

## 发布与回滚

- [ ] 将整个 `dist/` 作为不可分割版本发布，不逐文件覆盖。
- [ ] 验证 CDN 的 WASM MIME、压缩、缓存键和授权响应不被公共缓存污染。
- [ ] 验证上一版受保护产物仍可通过 `npm run rollback:production -- <buildId>` 恢复。
- [ ] 禁止回滚到公开 Core JS 或未通过最终审计的迁移产物。
