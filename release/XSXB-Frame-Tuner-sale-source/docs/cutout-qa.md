# 抠图工具按钮巡检记录

日期：2026-07-19

范围：单图抠图页面、结果预览画布、背景取样和局部修正按钮

## 已复现并修复

| 优先级 | 问题 | 修复结果 |
| --- | --- | --- |
| P1 | “区域恢复”只恢复被识别为主体的像素，背景或后续画笔/清空修改无法完整回滚。 | 选框内所有像素直接复制原图；恢复提示明确包含背景色。 |
| P1 | 在结果预览中取样时仍读取原图，所以背景由粉色改成绿色后再次清除，取到的仍是粉色。 | 结果画布取样读取当前 `resultImageData`，原图画布仍读取 `sourceImageData`。 |
| P1 | 新取样颜色追加到队尾，界面颜色仍显示旧样本。 | 最近一次取样提升到首位，并刷新对应连通种子点。 |
| P1 | 对已经被局部补成其他颜色的结果再次执行背景清除时，只更新自动样本，后续补色 repair 又把颜色画回来。 | 对当前结果中的可见变色区域追加透明连通清除 repair。 |
| P2 | “清除样本”没有解释作用范围，容易被理解为清空画布修正。 | 增加提示和状态反馈；该按钮只清除背景样本，已有局部修正记录保留，可用撤销回退。 |
| P2 | 取样按钮激活/取消没有明确反馈。 | 增加 `aria-pressed`、动态标题、取样中提示和取消提示。 |
| P2 | 取样状态没有随着切换到画笔/区域工具自动退出，导致按钮看似已切换但画布仍在取样。 | 选择任意非取样工具时统一取消背景/保护取样模式。 |
| P2 | 删除最后一个背景色样本后自动处理开关仍保持激活。 | 最后一个样本移除时同步关闭自动背景处理。 |

## 当前约定

- “背景清除”是两步操作：先进入取样，再点击原图或结果中的目标颜色。
- “清除样本”只移除自动背景颜色样本，不删除画笔、区域补色、清空区域等局部修正记录；基准变化后预览会按新参数重算。
- “区域恢复”是矩形范围的原图恢复，不是只恢复主体前景；如果只想恢复主体，应缩小框选范围。
- 结果画布取样到后续局部修正产生的可见颜色时，会保留历史修正并追加透明清除步骤，便于继续编辑和撤销。

## 回归验证

- Node 单元测试覆盖：最近样本提升、结果色透明清除、区域全量恢复、最后样本移除。
- Playwright 实际界面覆盖：背景取样、区域补色后从结果重新取样、快速画笔、取消指针事件、区域工具释放提交。
