# XSXB Frame Tuner 源码交付说明

本交付包基于当前工作区制作，已移除 Git 历史、依赖、构建产物、本机数据、缓存和私有部署配置。

## 重要说明

- 本版本不包含自动更新服务端接口、GitHub 更新检查、更新面板、更新按钮及相关浏览器请求。
- `updater.js`、`app_update.js` 及其对应测试不在交付包中。
- Skill 从当前本地项目目录安装，不依赖 GitHub 自动安装或更新。
- 版权信息和产品购买入口属于卖家公开品牌信息，已保留。

## 安装

```bash
npm ci
npm start
```

macOS 也可以双击 `start_xsxb_frame_tuner.command`。

## 验证

```bash
npm run check
npm run build:protected-core
npm test
```

完整本地服务集成测试需要先通过应用创建测试项目。WASM 相关测试需要先构建保护核心。

## Cloudflare 部署前配置

必须替换以下示例值：

- `example.com`：买家的正式域名。
- `00000000-0000-0000-0000-000000000000`：买家的 D1 数据库 ID。
- `admin`：建议修改为买家的管理员用户名。
- `.dev.vars.example` 和 `.env.local.example` 中的全部密钥占位符。

不要把 `.dev.vars`、`.env.local`、访问令牌、TOTP 密钥或生产数据库凭据提交到代码仓库。

## 未包含内容

- `.git/`、`node_modules/`、Rust `target/`。
- `dist/`、覆盖率、测试结果和历史保护构建。
- Codex、Playwright、Wrangler 和浏览器缓存。
- 本地项目注册表、导入素材、音频、工作区数据和导出结果。
- DOCX、PDF、说明书分页图片和 Office 临时锁文件。
