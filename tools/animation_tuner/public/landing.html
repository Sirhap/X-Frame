02 / WORKFLOW

从角色方向，
到透明动画包。

每一步都可以独立进入；已有素材时，直接从导入或抠图开始即可。

进入素材工作台 →
  1. 01

    2DCS 角色起稿

    根据任务选择 s / ct / p / sq / cs 模式，复制指令并在 Codex 中附上参考图。

  2. 02

    导入与整理

    导入图片序列或截取视频帧，确认名称、顺序、画布尺寸与统一 FPS。

  3. 03

    色键抠图

    按素材背景颜色完成抠图，再修复局部边缘并把参数同步到整组。

  4. 04

    多格式导出

    导出 PNG 序列、分页 Sprite Sheet 与清单；本地 FFmpeg 额外提供 GIF 和透明 MOV。
