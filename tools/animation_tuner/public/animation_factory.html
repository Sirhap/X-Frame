FACTORY FLOOR / 02 SIX WORKSTATIONS

今天，从哪道工序开始？

已有素材时直接进入对应工具；需要完整调参和项目管理时，打开核心工作台。

01 / CORE 核心工作台
PROJECT / CHARACTER / ANIMATION

CHARACTER + TUNING

角色起稿与动画调优

统一管理角色、动画组与逐帧参数，调整位置、碰撞框、附件、拖尾、音效和播放节奏。
  • 逐帧变换
  • 三类碰撞框
  • 附件与音效
  • Godot 同步
打开核心工作台
02 INGEST

IMAGE + VIDEO

导入与预处理

导入图片序列或提取视频帧，检查画布并建立动画组。
进入导入
03 ALPHA

CHROMA + LUMA

批量抠图

移除背景、修复边缘和局部区域，再把参数传播到整组。
进入抠图
04 OUTPUT

SEQUENCE + EXPORT

整理与导出

排序、删帧、循环分析，并输出多种可复用动画格式。
进入动画处理
05 SLICE

CONNECTED COMPONENTS

零散切图

识别散落在图片中的独立元素，预览、筛选并重新拼接为规则精灵表。
进入切片
06 VIDEO REPAIR

FFMPEG + LOCAL

视频去水印

框选带时间范围的水印区域，使用快速矩形或智能白印修复并导出视频。
进入视频修复

PIPELINE / 03 ONE CONTINUOUS WORKFLOW

一条流水线，
四次明确交付。

  1. 01

    素材入库

    保留源顺序、命名和画布信息，建立独立动画组。

  2. 02

    透明化

    按背景颜色完成色键抠图，再修复边缘与局部区域。

  3. 03

    逐帧调优

    统一处理变换、框体、节奏、附件、音效和攻击拖尾。

  4. 04

    打包交付

    整理循环与帧序，导出适合下一步制作的动画资产。
