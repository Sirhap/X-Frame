已有素材时直接进入对应工具；需要完整调参和项目管理时，打开核心工作台。

PROJECT / CHARACTER / ANIMATION

统一管理角色、动画组与逐帧参数，调整位置、碰撞框、附件、拖尾、音效和播放节奏。

02 导入

图片 + 视频

导入与预处理

03 抠图

色键 + 明度

批量抠图

移除背景、修复边缘和局部区域，再把参数传播到整组。

04 输出

序列 + 导出

连通组件

进入切片
06 视频修复

FFmpeg + 本地

框选带时间范围的水印区域，使用快速矩形或智能白印修复并导出视频。
进入视频修复

流程 / 03 连续工作流

一条流水线，
四次明确交付。

  1. 01

    素材入库

    保留源顺序、命名和画布信息，建立独立动画组。

  2. 02

    透明化

    按背景颜色完成色键抠图，再修复边缘与局部区域。

  3. 03

    逐帧调优

    统一处理变换、框体、节奏、附件、音效和攻击拖尾。

  4. 04

    打包交付

    整理循环与帧序，导出适合下一步制作的动画资产。
